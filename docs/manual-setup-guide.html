1 Generate Web Push VAPID Keys Locally

Run the built-in generator inside c:\Antygravity\parish. Never commit the private key to GitHub.

npm.cmd run generate-vapid

Keep the terminal output open—you will paste:

  • VITE_VAPID_PUBLIC_KEY into .env and Cloudflare Pages Environment Variables.
  • VAPID_KEYS_JSON into Supabase Edge Function Secrets (Step 3).

2 Provision Supabase Database, Storage & Admin Accounts

  1. In the Supabase Dashboard, click New Project (Free Plan, select us-east-1 East US closest to Charlotte, NC).
  2. Go to SQL Editor → New Query, paste the entire contents of supabase/migrations/001_initial_schema.sql, and click Run.
  3. Open a second SQL query, paste supabase/seed.sql, and click Run (populates parish info, regular schedules, and the sample June 1–7 bulletin).
  4. Go to Project Settings → API and copy your Project URL and anon public key into a new local .env file (copied from .env.example).

3 Deploy Push Notification Edge Function

The publish-and-notify Edge Function checks admin authorization, publishes the bulletin, and fans out encrypted Web Push alerts at $0 cost.

npx.cmd supabase login
npx.cmd supabase link --project-ref YOUR_PROJECT_REF
npx.cmd supabase secrets set VAPID_KEYS_JSON='PASTE_JSON_FROM_STEP_1' VAPID_SUBJECT='mailto:vicar@stmarysyroclt.org'
npx.cmd supabase functions deploy publish-and-notify --no-verify-jwt

Note: --no-verify-jwt allows CORS browser preflight requests while the function strictly verifies the user JWT via auth.getUser() and public.admin_users inside the Deno handler.

4 Push to GitHub & Enable Supabase Keep-Alive Cron

Supabase Free Tier pauses projects after 7 days with zero database activity. This repo includes .github/workflows/supabase-keep-alive.yml which runs every Monday & Thursday at 12:00 PM UTC.

  1. Create a new GitHub repository and push c:\Antygravity\parish (ensure .env is NOT committed—.gitignore blocks it).
  2. In GitHub, open Settings → Secrets and variables → Actions → New repository secret and add:
    • SUPABASE_URL (your https://xxxx.supabase.co)
    • SUPABASE_ANON_KEY (your public anon key — never use service_role here)
  3. Open the Actions tab and run "Keep Supabase Free Tier Alive" once manually to verify green status.

5 Deploy to Cloudflare Pages (Free Global CDN)

  1. Log into Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git.
  2. Select your GitHub repository and configure:
    • Framework preset: Vite
    • Build command: npm run build
    • Build output directory: dist
  3. Under Environment Variables (Production), add:
    • VITE_SUPABASE_URL
    • VITE_SUPABASE_ANON_KEY
    • VITE_VAPID_PUBLIC_KEY
  4. Click Save and Deploy.
  5. (Optional Custom Domain) Add app.stmarysyroclt.org under Custom domains and point a CNAME record in your domain DNS.
  6. Update Supabase → Authentication → URL Configuration → Site URL to your final Cloudflare Pages HTTPS URL.
